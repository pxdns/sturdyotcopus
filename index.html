01What it is

A desktop editor, delivered as a web page

The editor is the open-source Code - OSS workbench: the command palette, split editors, search, settings, keybindings and the extension model are the ones you already know. We add the parts that make it useful without an installer: Python that runs in the page, Java and Gradle tooling, GitHub sync, an AI assistant and a catalog of extensions that actually work on the web.

It is meant for places where installing a toolchain is slow or not allowed: a school lab, a borrowed laptop, a locked-down work machine, a tablet.

03Where things run

  1. Sync. Your working copy is committed to GitHub as one atomic commit.
  2. Chat. The code you select goes to your AI provider, using your own key. Nothing is sent unless you ask.
  3. Terminal. An optional remote runner gives you a real shell, a JDK, Gradle and Node. The IDE works without it.

04Launch modes

New tab
The default. Pin the tab and it behaves like an app.
Popup window
A compact window with no tab strip. Good for a second monitor.
about:blank window
Opens a blank window and hosts the IDE inside it; the address bar stays on about:blank.
Installed app
Use your browser's install button. The IDE gets its own window and icon.

06Limits

  • A browser tab cannot run a JVM or a native toolchain. Compiling and running Java and Gradle needs the remote runner.
  • Python runs the standard library. Packages with native code are not available.
  • Only extensions that can run in a browser are offered.
  • Browsers cannot guarantee background work while a tab closes. See how sync copes with that.
