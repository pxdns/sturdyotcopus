Extensions

A catalog of extensions that work in a browser.

The Extensions view lists extensions from the Open VSX registry, filtered at build time to those that can run on the web. Status: {{status:marketplace}}

01How the catalog is made

  1. The build scans Open VSX by popularity.
  2. It keeps extensions that ship browser code or are purely declarative (themes, grammars, snippets, keymaps).
  3. It keeps those with an open-source license, and drops very large ones.
  4. It reserves room per category so many small useful extensions are not crowded out by a few big ones.
  5. Files are served from this site. Installing an extension never contacts Open VSX from your browser.

02Why some extensions are missing

Most extensions run Node.js code and need a server-side process. They cannot run in a tab. Others are too large, have no clear license, or depend on something that is not in the catalog.

03Trust

Each install asks whether you trust the publisher. Extensions run in a web worker with no access to your files except through the editor's own interfaces. Their license files are included with their code.
