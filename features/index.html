02Browser or desktop

A browser tab and a desktop install make different trade-offs. This table is meant to help you choose, not to sell you the tab.

In a browser tabDesktop IDE
InstallNone. Works on any modern browser.Required, often needs admin rights.
Native toolchainsNo. Needs the remote runner.Yes.
ExtensionsOnly those that run on the web.Nearly all.
OfflineYour files are local; the app itself needs a connection to load.Fully offline.
Moving between machinesSign in with GitHub and continue.Set up each machine.
PerformanceGood for editing; heavy builds are slower.Native speed.

03Editor essentials

  • Command palette: F1 or Ctrl/Cmd Shift P
  • Split editors, diff editor, breadcrumbs, minimap, sticky scroll, bracket matching
  • Workspace-wide search and replace with regular expressions
  • Timeline and local history for recovering earlier versions of a file
  • JavaScript, TypeScript, JSON, CSS, HTML and Markdown language features running in web workers
  • An IntelliJ IDEA keymap, installable from the marketplace
