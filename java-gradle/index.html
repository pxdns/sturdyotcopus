Java and Gradle

Understanding Java and Gradle, within what a browser can do.

A browser tab has no JVM. These tools read your code; they do not compile or run it. Java: {{status:java}}   Gradle: {{status:gradle}}

01Java

  • Syntax diagnostics from a real Java parser, with error positions in the editor and Problems panel.
  • Structure. Classes, interfaces, enums, records, methods and fields in the Outline.
  • Snippets and completion for keywords, common JDK types and names in the file.

There is no type resolution, no cross-file refactoring and no compiler errors. Those need a JDK and a language server, which belong in the remote runner.

02Gradle

  • Outline of the plugins, dependencies, tasks and subprojects found in build.gradle, build.gradle.kts and settings.gradle, plus Gradle: Show Build Files to jump between them.
  • Snippets for plugins, repositories, dependencies, application and test blocks.
  • Inspections for deprecated configurations such as compile and testCompile, and for unbalanced braces.
  • Highlighting for Groovy build scripts, and Gradle: Run Task, which runs the task in the remote runner.

03Keymap

An IntelliJ IDEA keymap is included in the catalog, so familiar shortcuts work. It changes shortcuts only; it does not add IDE features.

04Not in a browser

  • Compiling, running, testing and debugging Java.
  • Running Gradle tasks and resolving dependencies.
  • Kotlin DSL (.gradle.kts) gets no dedicated grammar yet.
