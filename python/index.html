Python

Run Python without installing Python.

Your scripts run in a real CPython interpreter compiled to WebAssembly, inside the page. Status: {{status:python}}

01Runtime

The interpreter is Pyodide, a WebAssembly build of CPython. It ships with the IDE and is served from our own origin, so there is no third-party download at runtime.

  • Run the active file from the editor toolbar. Output appears in the Output panel.
  • input() opens a prompt in the editor, so interactive scripts work.
  • A stop button ends a runaway script by terminating its worker.
  • The standard library is available. Packages with native code are not.

02Editing

  • Diagnostics. Syntax errors are found by Python's own parser and shown as you type.
  • Outline. Classes, functions and methods appear in the Outline view and breadcrumbs.
  • Completion and hover. Keywords, built-ins, names defined in the file, and docs for the built-in functions.

This is not a full type-aware language server. It does not resolve imports across files or infer types.

03What does not work

  • Packages that need native code, and anything that opens sockets.
  • A debugger with breakpoints.
  • Virtual environments. There is one interpreter per tab.

For those, use the remote runner when it is available.
