Get started

Open it, then pick up where you left off.

No account is needed to start. Sign in with GitHub when you want to open a repository.

Open in this tab Popup window about:blank window

01First steps

  1. Open the IDE. A sample workspace is created in your browser.
  2. To work on GitHub, press F1 and run GitHub: Sign In, then GitHub: Open Repository.
  3. Edit. Changes are committed and pushed for you.
  4. Open a .py file and use the run button in the editor toolbar.
  5. To use the assistant, run AI: Set API Key.

02Shortcuts

Some shortcuts are claimed by the browser. Installing the IDE as an app, or using the popup window, frees most of them.

03Install as an app

In Chromium-based browsers use the install icon in the address bar, or the button above when it appears. In Safari, use File, Add to Dock. The app opens in its own window.
