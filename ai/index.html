AI assistant

An assistant that uses your model and your key.

A chat panel, an agent mode and optional inline suggestions. We do not resell models, and nothing is sent until you ask. Status: {{status:ai}}

01What it does

  • Chat in a side panel. It sees the open file or your selection, if you leave that box ticked.
  • Agent mode that can list, find and read files in the workspace and write files. Every write waits for your approval.
  • Explain and Fix commands in the editor context menu for the selected code.
  • Inline suggestions shown as ghost text. Off by default; switch on luma.ai.inlineCompletions.

02Bring your own model

ProviderHow it signs in
AnthropicYour API key, stored in your browser.
OpenAI-compatible endpointsYour API key and base URL (luma.ai.baseUrl). The endpoint must allow browser requests. GitHub Models can be used this way with a token you create for it.

Requests go from your browser directly to the provider you choose. We do not proxy them and we cannot see them.

03What it is not

This is not GitHub Copilot, and it does not use a Copilot subscription. GitHub offers no public way for a third-party app to call Copilot with a user's login, and we do not work around that.

04What leaves your browser

  • The text of your prompt, and the code you select or attach, go to the provider you chose.
  • Your API key goes to that provider and nowhere else.
  • Inline suggestions send the code around your cursor, only when they are switched on.
